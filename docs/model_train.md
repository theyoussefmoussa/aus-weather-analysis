# Modeling Phase

## Objective

Train, tune, and compare LightGBM classification models for predicting whether it will rain tomorrow.

The modeling phase uses the processed and feature-engineered datasets generated by the previous pipeline phases.

---

## Data Used

The modeling process uses the final datasets stored in:

`data/final/`

The training data contains:

- Training samples: 79,587
- Test samples: 19,897
- Features: 126
- Target: `RainTomorrow`

A stratified validation split was created from the training set for early stopping and hyperparameter tuning.

---

## Baseline Model

A baseline LightGBM classifier was trained using:

- Objective: Binary classification
- Metric: Average Precision
- Number of estimators: 1000
- Class imbalance handling using `scale_pos_weight`
- Early stopping: 50 rounds
- Random state: 42

The baseline model was saved as:

`models/lgbm_baseline.pkl`

---

## Hyperparameter Tuning

Optuna was used to optimize the LightGBM hyperparameters.

The tuning process used:

- TPE Sampler
- 75 trials
- Validation PR-AUC as the optimization metric
- The held-out test set was not used during tuning

The optimized parameters included:

- `num_leaves`
- `learning_rate`
- `max_depth`
- `min_child_samples`
- `subsample`
- `colsample_bytree`
- `reg_alpha`
- `reg_lambda`

The best parameters were stored in:

`src/utils/constants.py`

---

## Tuned Model

A final Tuned LightGBM model was trained using the best parameters obtained from Optuna.

The tuned model was saved as:

`models/lgbm_tuned.pkl`

The tuned model uses the complete 126-feature set.

---

## Model Comparison

The Baseline and Tuned models were compared on the held-out test set.

| Model | PR-AUC | ROC-AUC | Best Iteration | Non-zero Features |
|------|--------:|--------:|---------------:|------------------:|
| Baseline | 0.779255 | 0.908311 | 302 | 124 |
| Tuned | 0.807236 | 0.922616 | 730 | 126 |

---

## Key Findings

The Tuned model outperformed the Baseline model on both ranking metrics.

### PR-AUC

The Tuned model improved PR-AUC from:

`0.779255 → 0.807236`

### ROC-AUC

The Tuned model improved ROC-AUC from:

`0.908311 → 0.922616`

### Feature Usage

The Baseline model used 124 non-zero features out of 126.

The Tuned model used all 126 features.

---

## Feature Importance

Feature importance was analyzed using the Tuned LightGBM model.

The most important features included:

- `PressureDiff`
- `Pressure3pm`
- `TempRange`
- `TempChange`
- `TempHumidityInteraction`
- `Sunshine`
- `HumidityDiff`
- `MinTemp`
- `WindGustSpeed`
- `Evaporation`

Feature importance was visualized in the Evaluation notebook.

---

## Final Model Selection

The Tuned LightGBM model was selected as the final model because it achieved better PR-AUC and ROC-AUC performance than the Baseline model.

The selected model is:

`models/lgbm_tuned.pkl`

This model is used by the prediction pipeline and Streamlit application.

---

## Notes

- The test set remained untouched during hyperparameter tuning.
- Early stopping was used to determine the effective number of boosting iterations.
- `scale_pos_weight` was used to address class imbalance.
- Hyperparameter tuning was performed once using Optuna.
- The final repeatable training pipeline uses the selected best parameters rather than running Optuna on every execution.
